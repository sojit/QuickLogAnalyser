# Contributing

Use small branches and pull requests. Preserve product independence, bounded archive processing, original physical-line evidence, per-analysis isolation, local privacy and safe rendering. Add focused synthetic regression fixtures; never submit raw customer snapshots or identifying data.

Run Go tests and vet, the supported verification scripts, Node scroll/Highlights tests and package payload checks for affected changes. Browser behavior needs actual interaction evidence. Record limitations honestly; a passing compilation is not portable or browser qualification. Do not disable organizational application-control policies to run tests.

Update user documentation and CHANGELOG for behavior changes. Do not modify already-published tags or database migrations. Binaries, archives other than approved tiny synthetic fixtures, runtime storage and diagnostic exports must stay out of source commits. Release publication is a separate maintainer decision.
