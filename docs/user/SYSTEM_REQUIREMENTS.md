# System requirements

Windows x64/amd64 package, installed browser with JavaScript and loopback access, writable local working storage and adequate free disk for expanded snapshots/results. Go runtime baseline is Windows 10 / Server 2016 and later; the exact application OS/browser support matrix and hardware minimums remain unqualified. No administrator installation, external database or separate developer runtime is designed to be needed for the portable ZIP.

Internet is needed for initial source dependency downloads or GitHub access, not ordinary offline snapshot analysis. Go, Node, Git and PowerShell are development/testing tools, not portable-runtime prerequisites.

Measure application plus browser memory, duration and retained data on the chosen system; compressed archive size does not predict expanded storage. Current processing limits are not guaranteed hardware minima. Clean non-development Windows and native Linux testing remain pending.
